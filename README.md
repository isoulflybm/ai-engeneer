# 🤖 AI-Engineer Framework

**AI-Engineer Framework** — это автономная система разработки программного обеспечения на базе LLM (Gemma 4). Система имитирует работу полноценного IT-отдела, распределяя задачи между специализированными ИИ-агентами.

## 🌟 Архитектура системы

Проект построен на принципе разделения ответственности:
- **Architect (Архитектор)**: Превращает ваше ТЗ в атомарный JSON-план разработки.
- **Developer (Разработчик)**: Реализует каждый шаг плана, используя полный контекст проекта (256k токенов).
- **QA Engineer (Инженер по качеству)**: Анализирует логи ошибок из Docker и составляет отчет об исправлениях.
- **Documentalist (Техписатель)**: Создает финальную документацию на основе анализа кода.
- **Project Manager**: Управляет файловой системой, Git-версионностью и состоянием проекта.

## 🛠 Технологический стек

- **LLM**: Gemma 4 (через Ollama)
- **Language**: Python 3.10+
- **Infrastructure**: Docker & Docker Compose
- **Version Control**: Git (via GitPython)

### Последний штрих 🏁

Теперь у вас есть **полный комплект**:
1. **Конфигурация** (`config.py`)
2. **Интеллект** (`agents/`)

Этот проект теперь является полноценным программным продуктом. Вы можете запустить его, ввести любое ТЗ (например: *"Создай Telegram-бота для учета расходов с базой данных PostgreSQL"*), и система сама спроектирует, напишет, протестирует и задокументирует это приложение.
